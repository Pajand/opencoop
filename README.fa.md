## اوپن‌کوپ چیست؟

**هر دستگاهی را به یک سرور کدنویسی مشترک تبدیل کنید. کل تیم شما روی ONE پروژه کار می‌کنند — از هر کجای دنیا.**

اوپن‌کوپ یک **پلاگین اوپن‌کد** است که به چندین توسعه‌دهنده (هر کدام با هوش مصنوعی خود) اجازه می‌دهد به طور همزمان روی **یک پوشه پروژه** که روی **یک ماشین** میزبانی می‌شود کار کنند.

### چطور کار می‌کند؟ (ساده!)

```
  لپ‌تاپ شما (هاست)                     لپ‌تاپ هم‌تیمی (ریموت)
  ┌──────────────────┐                  ┌──────────────────┐
  │  پروژه شما       │                  │  هم‌تیمی         │
  │  /home/you/app   │◄──── اینترنت ────│  اوپن‌کد + AI    │
  │                  │   (از طریق تانل) │                  │
  │  سرور اوپن‌کوپ   │                  │  پلاگین اوپن‌کوپ │
  │  پورت 31313      │                  │  (وصل به شما)    │
  └──────────────────┘                  └──────────────────┘
        ▲                                        │
        │                                        ▼
        │                               هوش مصنوعی هم‌تیمی فایل‌های
        │                               شما را بلادرنگ می‌خواند و می‌نویسد!
        │
  هر تغییر ثبت می‌شود:
  ✅ چه کسی چه فایلی را تغییر داد
  ✅ diff کامل (نمایش قرمز/سبز)
  ✅ زمان دقیق
```

### مثال واقعی

1. **شما** یک پروژه روی لپ‌تاپ خود دارید در `/home/you/my-app`
2. وب‌یوآی اوپن‌کوپ را باز می‌کنید → حالت **HOST** را انتخاب می‌کنید → پوشه را انتخاب می‌کنید → **Generate Invite Link** را می‌زنید
3. لینک را برای هم‌تیمی می‌فرستید (مثلاً `https://abc123.tinyfi.sh/ui/invite/xyz`)
4. **هم‌تیمی** پلاگین را نصب می‌کند، لینک شما را می‌چسباند، **Connect** را می‌زند
5. حالا هوش مصنوعی هم‌تیمی می‌تواند فایل‌های پروژه **شما** را بخواند، بنویسد و ویرایش کند — انگار روی سیستم خودش است!
6. هر دوی شما هر تغییر را در صفحه **Changes** می‌بینید با **نام تغییر دهنده** و **diff تصویری**

**بدون Git push/pull. بدون اشتراک صفحه. بدون «فایل را بفرست». فقط با هم زنده کدنویسی کنید.**

### مفاهیم کلیدی

| مفهوم | توضیح |
|-------|-------|
| **HOST (میزبان)** | یک دستگاه که فایل‌های واقعی پروژه را دارد. آن‌ها را از طریق تانل امن روی اینترنت به اشتراک می‌گذارد. |
| **REMOTE (مهمان)** | هر دستگاه دیگری که به میزبان وصل می‌شود. هوش مصنوعی آن‌ها روی فایل‌های میزبان کار می‌کند انگار محلی است. |
| **لینک دعوت** | یک URL امن که میزبان تولید می‌کند. شامل آدرس تانل + توکن دسترسی است. آن را با هم‌تیمی‌ها به اشتراک بگذارید. |
| **ردیابی تغییرات** | هر خواندن/نوشتن/ویرایش فایل با نام کاربر، زمان و diff کامل ثبت می‌شود. |
| **قفل فایل** | جلوگیری از ویرایش همزمان یک فایل توسط دو نفر (جلوگیری از تداخل). |

### به‌زودی 🚀

- **داشبورد مدیر**: مدیریت اعضای تیم، دسترسی‌ها و مجوزها
- **حل تداخل**: ادغام هوشمند وقتی دو کاربر خطوط یکسان را ویرایش می‌کنند

**تا ۵۰ توسعه‌دهنده** می‌توانند همزمان با ردیابی کامل همکاری کنند.

## نصب

### نصب از npm (توصیه شده)

```bash
npm install -g @opencoop/opencode-plugin
```

سپس در فایل `~/.config/opencode/opencode.json` اضافه کنید:

```json
{
  "plugin": ["@opencoop/opencode-plugin"],
  "mcp": {
    "opencoop": {
      "type": "remote",
      "url": "http://localhost:31313/sse",
      "enabled": true
    }
  }
}
```

### نصب از GitHub

```bash
git clone https://github.com/Pajand/opencoop.git
cd opencoop
npm install
npm run build
npm link
```

سپس در `~/.config/opencode/opencode.json`:

```json
{
  "plugin": ["opencoop"],
  "mcp": {
    "opencoop": {
      "type": "remote",
      "url": "http://localhost:31313/sse",
      "enabled": true
    }
  }
}
```

## شروع سریع

1. **نصب** پلاگین (`npm install -g @opencoop/opencode-plugin`)
2. **ری‌استارت** اوپن‌کد
3. **باز کردن** `http://localhost:31313/ui` در مرورگر
4. **انتخاب** حالت HOST (مالک پروژه) یا REMOTE (عضو تیم)

## استفاده

### حالت HOST (مالک پروژه)

1. حالت **HOST** را در رابط وب انتخاب کنید
2. **پوشه پروژه** را انتخاب کنید
3. روی **ایجاد لینک دعوت** کلیک کنید
4. لینک را **با اعضای تیم به اشتراک بگذارید** (حداکثر ۵۰ عضو)

لینک دعوت از **تونل SSH خودکار** از طریق tinyfi.sh استفاده می‌کند (`https://xxx.tinyfi.sh`)، پس اعضای تیم حتی پشت NAT، فایروال یا VPN هم به سرور شما دسترسی دارند.

### حالت REMOTE (عضو تیم)

1. **پلاگین را روی ماشین خود نصب کنید**
2. کانفیگ MCP را به `opencode.json` اضافه کنید
3. **اوپن‌کد را ری‌استارت کنید**
4. `http://localhost:31313/ui` را باز کنید
5. حالت **REMOTE** را انتخاب کنید
6. **لینک میزبان را Paste کنید**
7. روی **اتصال** کلیک کنید — تمام.

سرور محلی شما حالا **هر فراخوانی ابزار را از طریق تونل به میزبان فوروارد می‌کند**، پس هوش مصنوعی شما **به‌صورت زنده پوشه پروژه میزبان** را می‌خواند و می‌نویسد.

### تونل SSH خودکار (بدون نیاز به تنظیم)

وقتی حالت HOST فعال باشد، اوپن‌کوپ به‌صورت خودکار:

1. یک تونل SSH معکوس به `tinyfi.sh` باز می‌کند
2. ترافیک را به `http://localhost:31313` فوروارد می‌کند
3. از آدرس عمومی `https://xxx.tinyfi.sh` در تمام لینک‌های دعوت استفاده می‌کند

**پیش‌نیازها:** Node.js 18+، اوپن‌کد، و کلاینت SSH (روی تقریباً همه سیستم‌ها از پیش نصب است).

## ابزارهای MCP

پس از اتصال، هوش مصنوعی شما به ۱۵ ابزار دسترسی دارد:

| ابزار | توضیحات |
|-------|---------|
| `read_file` | خواندن محتوای فایل از پروژه مشترک |
| `write_file` | ایجاد یا بازنویسی فایل‌ها |
| `edit_file` | ویرایش هدفمند با جستجو و جایگزینی |
| `list_files` | فهرست کردن محتوای پوشه |
| `search_files` | جستجوی فایل‌ها با الگوی glob |
| `grep_content` | جستجوی محتوای فایل با regex |
| `directory_tree` | دریافت نمای ساختار پوشه |
| `lock_file` | دریافت قفل انحصاری قبل از ویرایش |
| `unlock_file` | آزاد کردن قفل پس از ویرایش |
| `view_changes` | مشاهده تغییرات اخیر اعضای تیم |
| `view_stats` | مشاهده آمار پروژه |
| `who_is_online` | مشاهده کاربران آنلاین |
| `invite_member` | ایجاد لینک دعوت برای اعضای جدید |
| `list_members` | فهرست تمام اعضای تیم |
| `revoke_access` | لغو دسترسی یک عضو |
| `opencoop_guide` | نقطه شروع AI — اول صدا می‌زند؛ قوانین و سؤال تأیید را یاد می‌گیرد |
| `list_snapshots` | فهرست نسخه‌های قبلی ذخیره‌شده یک فایل |
| `rollback_file` | جبران اشتباه: بازگردانی فایل (فقط path = برگرداندن آخرین تغییر) |

## راهنمای عامل هوش مصنوعی

**اگر شما یک عامل هوش مصنوعی هستید که این متن را می‌خوانید، مراحل زیر را دقیقاً دنبال کنید:**

### مرحله ۱: نصب

```bash
which opencode || echo "OpenCode نصب نیست"
npm install -g @opencoop/opencode-plugin
```

### مرحله ۲: پیکربندی

پلاگین را به `~/.config/opencode/opencode.json` اضافه کنید:

```json
{
  "plugin": ["@opencoop/opencode-plugin"],
  "mcp": {
    "opencoop": {
      "type": "remote",
      "url": "http://localhost:31313/sse",
      "enabled": true
    }
  }
}
```

### مرحله ۳: تأیید

```bash
npm list -g @opencoop/opencode-plugin
```

### مرحله ۴: دسترسی به رابط وب

```
http://localhost:31313/ui
```

### عیب‌یابی

```bash
# ۱. آیا اوپن‌کد نصب است؟
which opencode || echo "NOT IN PATH"

# ۲. آیا پلاگین نصب است؟
npm ls -g @opencoop/opencode-plugin 2>&1

# ۳. آیا سرور HTTP بالاست؟
curl -s --max-time 3 http://localhost:31313/health || echo "SERVER DOWN"

# ۴. آیا SSE کار می‌کند (نه HTML)؟
curl -s -o /dev/null -w '%{http_code} %{content_type}\n' --max-time 3 -H 'Accept: text/event-stream' http://localhost:31313/sse
```

### نکات پلتفرمی

**ترمکس (اندروید):**
- باینری اوپن‌کد معمولاً توی `$PREFIX/bin/opencode` یا `$HOME/.opencode/bin/opencode` هست.

**ویندوز:**
- مسیر کانفیگ: `%USERPROFILE%\.config\opencode\opencode.json`
- کش پلاگین: `%USERPROFILE%\.cache\opencode\packages\@opencoop`

**مک:**
- Homebrew: `/opt/homebrew/bin/opencode`
- curl script: `~/.opencode/bin/opencode`

## عیب‌یابی

### پلاگین شناخته شده ولی UI بالا نمیاد / MCP شروع نمیشه

1. **نسخه پلاگین خیلی قدیمیه**: باید `1.14.0` یا بالاتر باشه.
2. **کش قدیمی پلاگین**:
   ```bash
   rm -rf ~/.cache/opencode/packages/@opencoop
   ```
3. **پورت 31313 اشغاله**: با `lsof -i :31313` چک کنید.

### ام‌سی‌پی قرمز می‌ماند / وصل نمی‌شود

1. مطمئن شوید رابط وب اوپن‌کد باز است.
2. بررسی سرور: `curl http://localhost:31313/health`
3. بررسی SSE: `curl -N -H 'Accept: text/event-stream' http://localhost:31313/sse`
4. مطمئن شوید آدرس `url` با `/sse` تمام می‌شود (نه `/mcp`).

### لینک دعوت IP محلی می‌دهد به‌جای آدرس تونل

1. **بعد از نصب/آپدیت، اوپن‌کد را کامل ری‌استارت کنید**.
2. **در اولین اجرا چند ثانیه صبر کنید** — تونل SSH وصل می‌شود.
3. **حالت باید HOST و ذخیره‌شده باشد**.
4. **نشانگر را ببینید**: سبز = لینک‌ها با تونل‌اند؛ قرمز = علت خطا.

### ابزارها خطا می‌دهند

رابط وب (`http://localhost:31313/ui`) را باز کنید، حالت HOST یا REMOTE را انتخاب و پوشه پروژه را تنظیم کنید.
